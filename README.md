# Arwanda Digital Hub

React + Vite portfolio website reconstructed from the supplied reference screenshots.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub + Vercel

1. Create a new GitHub repository.
2. Upload/push all files in this project.
3. In Vercel, import the GitHub repository.
4. Framework Preset: **Vite**.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

No environment variables are required.

## Notes

- Navigation uses section anchors.
- The contact form opens the visitor's email application with the form contents prefilled.
- The screenshot/feedback areas are intentionally placeholders so no fabricated client material is presented.
- Replace placeholder visuals with real portfolio/client images when available.
